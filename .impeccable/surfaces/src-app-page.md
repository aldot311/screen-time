# Surface brief: Screen-Time landing page

Scope: the public page at / that hackathon judges and brand managers land on. Mode: Persuade.
Audience and job: someone deciding in under a minute whether Screen-Time is real, then opening a real report.
Constraints: the same light world as the app (DESIGN.md); every claim backed by a real run or docs/ACCURACY.md; nothing synthetic shown as real.
Direction source: extends the user-pinned app direction (Linear/Stripe, light); no concept roll.

## Direction contract
THESIS: Show, don't claim. The first viewport is a real Meta run replaying itself, not an illustration of one.
OWN-WORLD: The app's world unchanged: cool paper ground, ink, hairlines, lime only for on-screen seconds (plus the mark and the block behind "seen."), verdict colours only for verdicts, violet only for spoken mentions, Geist Mono only for timecodes.

SIGNATURE: the strip filling in time with the replay.

# Screen-Time

Measures how long a brand is actually on screen in creator video. Built on Meta's SAM 3.1, Muse Spark and Muse Voice
Transcribe for the Meta Global AI Developer Hackathon (startup track, Aetrai). Everything in this repo was built during
the hackathon, starting Oct 28, 2026.

See [docs/SPEC.md](docs/SPEC.md).
